# 清洁一下 · 卡赫 3D 清洁实验室

面向 WaytoAGI「1024 超能 Coding 周末·苏州」创作的品牌概念互动原型。围绕四款卡赫产品，把观察污渍、选择动作、清洁解压与品牌故事连接起来。

## 立即试玩

**解压后双击根目录的 index.html 即可开始。无需安装依赖。**

- 游戏脚本、产品图片、场景和音效均本地化，无 CDN、账号或 API 依赖。
- 建议使用支持 WebGL 的现代浏览器。设备音效默认关闭，可主动开启。
- 也可在此目录运行以下命令，再访问 http://127.0.0.1:8765/ ：

    python3 -m http.server 8765 --bind 127.0.0.1

静态网站部署时保持目录关系，上传整个项目或至少上传 index.html、style.css、dist/ 与 assets/。

## 作品体验

| 产品 | 场景与清洁判断 |
| --- | --- |
| PUZZI 8-1 | 沙发咖啡渍与爪印：先喷抽去污，再停止喷水抽吸余水；完成后仍需通风晾干。 |
| WV 2 | 玻璃干手印需辅助喷瓶润湿、清洁布擦松，再刮吸；已有湿污膜可直接吸除。 |

四套场景、八张生活委托、参考图片建模的产品展示、有效清洁 +1、分层动作拟音、残留定位、成果对比和图文卡收藏均已集成。

## 操作说明

- 鼠标或触屏按住移动清洁；工具栏切换动作，观察模式可旋转场景。
- 清洁布默认需要移动；设置中的「轻松擦洗」支持按住停留。
- 键盘聚焦画布后：方向键移动、空格清洁、1–3 换工具、Esc 停止。
- 「查找残留」靠近剩余污渍或水痕；「清洁成果卡」可查看前后对比并保存 PNG。
- 新用户从咖啡短委托开始；已有进度自动恢复。没有倒计时或清洁失败惩罚。
- 声音、音量、轻松擦洗和画质设置保存在本机。手机下委托、卡册及资料入口位于可展开区域。

## 图文卡与试玩金卡

每款产品首次完成获得对应知识卡；之后随机抽取，每张未拥有普通卡的权重为已拥有卡的 3 倍。普通卡共 8 张，包含官方产品知识与文化清洁故事，图片和文字出处可在卡片中查看。

每轮完整清洁独立有 **1%** 概率附带金卡，无保底。同轮刷新、重复开卡或进入卡册不会重新抽取。

## 项目目录

    kahegame/
    ├── index.html                # 游戏入口
    ├── style.css                 # 响应式样式
    ├── dist/game.js              # 已构建、可离线运行的完整脚本
    ├── src/                      # Three.js 场景、产品、流程与交互源码
    ├── assets/
    │   ├── references/           # 四款产品参考图及兼容预览
    │   ├── models/               # 四款 GLB 模型及清单
    │   ├── cards/                # 官方图文卡图片和来源清单
    │   ├── manuals/              # 游戏引用的官方说明书
    │   ├── sources.json          # 产品、参考图及说明书出处
    │   └── THREE-LICENSE.txt      # Three.js MIT 许可证
    ├── docs/                     # 提交说明与桌面、手机预览
    ├── tests/                    # 核心回归与资源完整性检查
    ├── package.json
    ├── package-lock.json         # 锁定依赖版本
    └── .gitignore

assets/models/ 的 GLB 是供查看和继续编辑的模型导出；游戏实际使用 src/products.js 构建同源网格，因此不需要联网加载模型。

## 开发与验证

试玩使用已构建的 dist/game.js。修改源码时再安装开发依赖：

    npm ci
    npm run build
    npm test

npm test 本身只需 Node.js，可在没有 node_modules 的情况下运行。检查包括产品步骤约束、余水完成条件、防刷反馈、旧存档兼容、图文卡概率规则以及提交文件完整性。

## 存档与素材说明

存档仅保存在当前浏览器本机，不上传服务器。请固定入口：双击本地文件与 HTTP 地址使用不同存储环境。重来会覆盖当前轮次，已收集卡片与任务记录保留。

本作品为非官方品牌概念试玩。产品模型依据提供的参考照片手工搭建，非官方 CAD；背面和比例采用视觉近似。场景、污层与音效由项目程序制作，操作速度、水箱与状态条均为玩法示意，不代表实测性能。地区型号与附件差异在资料和卡片中标注。

更多资料见 [提交说明](docs/SUBMISSION.md) 和 [素材与第三方声明](docs/ATTRIBUTION.md)。
